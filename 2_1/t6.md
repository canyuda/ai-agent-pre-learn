| 方法 | URL | 作用 | 说明 |
| --- | --- | --- | --- |
| GET | /agents | 列出所有 Agent | 支持 ?model=gpt-4o 过滤，过滤用查询参数，不为它单独设计 URL |
| POST | /agents | 创建 Agent | 201；非幂等，重复提交创建多条 |
| GET | /agents/{id} | 查看单个 Agent | 幂等，404 表示不存在 |
| PATCH | /agents/{id} | 部分更新（改名、换模型） | 只发改过的字段 |
| DELETE | /agents/{id} | 删除 Agent | 204；幂等；同时级联解除该 Agent 的工具注册 |


| 方法 | URL | 作用 | 说明 |
| --- | --- | --- | --- |
| GET | /tools | 列出所有 Tool | 支持 ?search= 模糊搜索 |
| POST | /tools | 注册新 Tool | 201 |
| GET | /tools/{name} | 查看单个 Tool | 注意：题目只给了 Tool 的 name 没给 id，URL 标识符跟着资源的唯一键走 |
| DELETE | /tools/{name} | 下架 Tool | 204；幂等 |

| 方法 | URL | 作用 | 说明 |
| --- | --- | --- | --- |
| GET | /agents/{id}/tools | 查看 Agent 已注册的工具 | 嵌套子资源 |
| POST | /agents/{id}/tools | 注册一个工具 | body 传 {"name": "search"}；非幂等 |
| DELETE | /agents/{id}/tools/{tool_name} | 解除注册 | 幂等；删除指向“关系项”的 URL，不用 DELETE 带 body（很多客户端不支持） |
| GET | /tools/{name}/agents | 反查：哪些 Agent 在用这个工具 | 多对多应该双向可导航 |
